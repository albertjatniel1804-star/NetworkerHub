# NetworkerHub 🚀

NetworkerHub es una plataforma web en desarrollo orientada a networkers y vendedores independientes.

El objetivo del proyecto es proporcionar una herramienta donde los usuarios puedan crear su presencia comercial, mostrar productos y gestionar clientes potenciales desde una misma plataforma.

## 🛠️ Tecnologías

- Python
- FastAPI
- Uvicorn
- Jinja2
- HTML
- CSS
- Git
- GitHub

## ▶️ Instalación

Clonar el repositorio:

````bash
git clone https://github.com/albertjatniel1804-star/NetworkerHub.git

Crear el entorno virtual: python -m venv .venv

Activar el entorno virtual en Windows: .\.venv\Scripts\Activate.ps1

Instalar las dependencias: pip install -r requirements.txt

Ejecutar el servidor: uvicorn app.main:app --reload

La aplicación estará disponible en: http://127.0.0.1:8000
````
